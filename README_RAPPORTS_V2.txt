- Formulaire complet : contexte, personnes, véhicules, saisies, chefs d'accusation, Miranda, droits invoqués, preuves, décision.

- Circonstances aggravantes séparées.

- Aperçu tablette en Markdown.
- Bouton « Copier pour la tablette » depuis la liste et depuis la consultation.
- Export tablette complet, sans numéro interne R-2026-XXXX et sans indication de casier.
- Markdown : # / ## / ### / **gras** / *italique* / listes.

Installation : remplacer les fichiers du portail GitHub par ceux de ce ZIP.
