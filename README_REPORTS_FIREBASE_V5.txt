RAPPORTS FIREBASE V5 — GITHUB

Corrige la synchronisation des rapports entre agents :
- rapport créé par un agent -> Firestore
- affichage temps réel dans Mes rapports
- affichage dans BD Rapports
- affichage dans le profil Supervision de l'agent
- rapports disciplinaires isolés dans une collection confidentielle
- migration idempotente des rapports locaux réels (les anciens rapports de démonstration sont ignorés)
